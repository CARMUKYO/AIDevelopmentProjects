# AIDevelopmentProjects

Collection of AI-assisted development projects.

## Projects

- [expenseTracker](./expenseTracker/) — Stdlib-only Python expense tracker CLI with Quickshell bar widget.
- [todoRestAPI](./todoRestAPI/) — TypeScript/Express REST API for todos (SQLite + Zod + Vitest).
- [urlShortener](./urlShortener/) — High-throughput Go URL shortener service with analytics (PostgreSQL/SQLite + Redis).
- [weatherDashboard](./weatherDashboard/) — Terminal weather dashboard consuming the Open-Meteo API (Python + Typer + Rich + HTTPX).
